    Skill 1: Append Queries (`Table.Combine`) — Stacking Rows Vertically

    Use Append when you have two or more tables with the same column structure that belong in one single master table.

    M-Syntax & Variations
    // Variation A: Append Two Queries
    CombinedTwo = Table.Combine({North_Subs, South_Subs})

    // Variation B: Append Three or More Queries
    AllRegions = Table.Combine({North_Subs, South_Subs, West_Subs, East_Subs, Central_Subs})
    Home Tab → Combine Group → Append Queries (or Append Queries as New)
    Real-World Use Cases & Traps
    • Use Case 1: Regional circle dumps (e.g., JioWave Maharashtra + Karnataka + Delhi subscriber exports).
    • Use Case 2: Monthly billing files (Rev_Apr25.csv, Rev_May25.csv).
    • Trap #1 (Case Sensitivity): Column City and column city will NOT stack into one column—Power Query creates two separate columns!
    • Trap #2 (Self-Append): Clicking Append Queries (instead of Append as New) modifies your active table in place.

    Skill 2: Merge Queries (`Table.NestedJoin`) — All 6 Join Kinds

    Merge joins two tables sideways by matching one or more key columns—replacing Excel's `VLOOKUP` and `XLOOKUP` forever.

    // Syntax: Table.NestedJoin(LeftTable, {LeftKey}, RightTable, {RightKey}, "NewColName", JoinKind.LeftOuter)
    MergedTowers = Table.NestedJoin(Subscribers, {"home_tower_id"}, Towers, {"tower_id"}, "TowerInfo", JoinKind.LeftOuter),
    ExpandedTowers = Table.ExpandTableColumn(MergedTowers, "TowerInfo", {"city", "tower_tier", "generation"})
    The 6 Power Query Join Kinds Explained on JioWave
    Join Kind What Survives in Output JioWave Analyst Use Case
    1. Left Outer (Default) All rows from Left table + matching info from Right table Keep all 28,000 subscribers and pull city & tower_tier from towers
    2. Right Outer All rows from Right table + matching rows from Left Keep all 279 towers even if 0 subscribers live near a newly built tower
    3. Full Outer Every row from BOTH tables (matched or unmatched) Complete reconciliation audit between Billing System and CRM System
    4. Inner Join ONLY rows that have a match in BOTH tables Filter subscribers down to only those who have at least 1 plan migration
    5. Left Anti (Audit Gold!) Rows in Left table that have NO match in Right table Find "Ghost Subscribers" (subscribers in CRM with 0 rows in revenue_monthly!)
    6. Right Anti Rows in Right table that have NO match in Left table Find "Zero-Subscriber Towers" (towers with 0 assigned home subscribers)

    Skill 3: Pivot Column (`Table.Pivot`) — Turning Row Values into Headers

    Pivot takes unique text values from ONE column and rotates them into brand-new column headers, aggregating a numeric value underneath.

    M-Syntax & UI Path
    Select Attribute Column → Transform Tab → Pivot Column → Choose Values Column
    Table.Pivot(
      Source,
      List.Distinct(Source[revenue_month]),
      "revenue_month",
      "total_inr",
      List.Sum
    )
    When to Use Pivot vs. Avoid Pivot
    • Great for: Reshaping Key-Value sensor/system logs (where Metric_Name has rows "Latency", "Uptime", "Jitter") into separate numeric columns.
    • Great for: Exporting a board-ready summary table back to Excel/CSV.
    • Advanced Options: Don't forget to expand Advanced Options in the Pivot dialog to pick Sum, Average, Count, or Don't Aggregate!

    Skill 4: Unpivot (`Table.UnpivotOtherColumns`) — The #1 Real-World Fix

    Finance and Marketing teams love sending wide Excel sheets with 12 month columns (`Apr-25` to `Mar-26`). Unpivoting converts them into clean `Attribute` + `Value` rows!

    Variation 1: Unpivot Columns

    Unpivots only the specific columns you selected. Risk: Next month when Jul-26 is added to Excel, Power Query ignores it!

    Variation 2: Unpivot Other Columns (BEST!)

    Select your fixed anchor column (e.g., subscriber_tier) → Right-click → Unpivot Other Columns. Automatically captures any new months added next quarter!

    Variation 3: Unpivot Only Selected Columns

    Hardcodes the exact list of selected columns and ignores newly added columns—useful when an Excel sheet has trailing "Total" or "Notes" columns.

    // Enterprise-safe M syntax (automatically handles future month columns!):
    UnpivotedBudget = Table.UnpivotOtherColumns(PivotedTable, {"subscriber_tier"}, "Billing_Month", "Revenue_INR")

    Skill 5: Group By (`Table.Group`) — Summarizing 564,274 Usage Logs

    Group By works just like SQL `GROUP BY` or an Excel PivotTable—collapsing granular transaction rows into summary metrics.

    // Advanced Group By on `usage_monthly.csv` to profile every subscriber's lifetime data usage:
    SubscriberUsageProfile = Table.Group(UsageSource, {"subscriber_id"}, {
      {"Total_Data_GB", each List.Sum([data_consumed_gb]), type number},
      {"Avg_Monthly_GB", each List.Average([data_consumed_gb]), type number},
      {"Active_Months", each Table.RowCount(_), Int64.Type},
      {"Overage_Months", each List.Sum([is_overage]), Int64.Type}
    })

    Skill 5B: Hidden Pro Feature 00:52 – 00:58

    Pro Trick: Group By → Operation = "All Rows" (Keeping Detail + Summary!)

    Normally, Group By destroys individual rows. Selecting All Rows keeps the entire sub-table inside a clickable cell—letting you compute each subscriber's share of their city's revenue right inside Power Query!

    How "All Rows" Works
    1. Go to Transform → Group By → Advanced.
    2. Group by city.
    3. Aggregation 1: City_Total_Subs = Count Rows.
    4. Aggregation 2: Sub_Details = Operation: All Rows.
    5. Click the Expand (↔) icon on Sub_Details to bring back every individual subscriber row alongside their city's total!
    Another Killer Use: Finding Each Customer's Latest Plan

    In subscriptions.csv (32,728 rows), sort by start_date descending, Group By subscriber_id with All Rows, and extract row 0 (Table.First([Sub_Details])) to get every subscriber's current active plan in 1 step!

    Skill 6: Date & Time Operations (`Date.AddMonths`, `Duration.Days`, Fiscal Year)

    Every telecom KPI—tenure, contract expiry, billing cycle, and Indian Fiscal Year—relies on Power Query's Date & Time ribbon.

    Essential Power Query Date & Time Functions Applied to JioWave
    Business Need Power Query M Syntax JioWave Example
    1. Parse Mixed Dates (`29/07/2025` & `2025-11-06`) Date.FromText([signup_date], "en-GB") Fixes all 4,200 slash-formatted dates in subscribers.csv
    2. Indian Fiscal Year (`Apr–Mar`) if Date.Month([Date]) >= 4 then Date.Year([Date]) + 1 else Date.Year([Date]) 2025-05-01 ➔ FY 2026
    3. End of Month / Start of Month Date.EndOfMonth([signup_date]) Aligns daily signup dates to monthly billing tables
    4. Tenure in Days (Date Subtraction) Duration.Days([churn_date] - [signup_date]) Verifies exact active lifespan before churn
    5. Promo Expiry Date (+6 Months) Date.AddMonths([start_date], 6) Pinpoints exact date PL015 6-month free trial ends!
    Skill 7: Split, Extract & Format 01:08 – 01:18

    Skill 7: Split, Extract & Format — Cleaning Every Text & ID Column

    Master the three text surgery menus on the `Transform` and `Add Column` ribbons.

    1. Split Column (`Splitter.*`)
    • By Delimiter: Split "Salaried-IT" at "-" into Category (Salaried) and Sub_Type (IT).
    • By Number of Characters: Split "SUB026196" after first 3 chars into Prefix (SUB) and Numeric_ID (026196).
    • By Non-Digit to Digit: Automatically separates letters from numbers without needing a delimiter!
    2. Extract (`Text.Before/After/Range`)
    • Text Before Delimiter: Text.BeforeDelimiter("JioBasic 99", " ") ➔ "JioBasic".
    • Text After Delimiter: Text.AfterDelimiter("JioBasic 99", " ") ➔ "99" (extracts rental price directly from plan name!).
    • Text Range: Text.Middle("TW0081", 2, 4) ➔ "0081".
    3. Format (`Text.Proper`, `PadStart`)
    • Trim & Clean: Removes accidental spaces and hidden newlines.
    • Capitalize Each Word: Converts "MUMBAI" & "mumbai" ➔ "Mumbai".
    • Add Prefix / Pad: Text.PadStart("81", 4, "0") turns "81" into "0081" so tower IDs always match TW0081!
    Skill 8: Parameters 01:18 – 01:28

    Skill 8: Parameters (`Manage Parameters`) — Making Your Report Portable & Dynamic

    Hardcoding file paths or threshold numbers inside M queries is a rookie mistake. Parameters turn static queries into configurable templates.

    Step-by-Step: Creating a Parameter
    1. Click Home Tab → Manage Parameters → New Parameter.
    2. Name: pDataPath | Type: Text | Current Value: C:\JioWave_CSV_Files\.
    3. Open any CSV query's Source step (gear icon ⚙️) → change File path dropdown from Text to Parameter → select pDataPath!
    4. To share your `.pbix` with a client or evaluator, they simply click Transform Data → Edit Parameters and paste their folder path!
    3 High-Value Business Parameters for JioWave
    • pDataPath (Text): Folder path for all 9 JioWave CSVs.
    • pCapexCutoffDate (Date = 2023-04-01): Dynamically defines which towers count as "Recent Capex" vs. "Legacy".
    • pHighUsageGB (Decimal = 50.0): Filters out-of-bundle "Data Hog" events inside usage_monthly.csv.
