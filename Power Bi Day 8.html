    Commerce & Operations Analogy: Warehouse Capacity Utilization

    Think of cell towers like regional warehouses. If a warehouse operates below 50% capacity, the company wasted capital building too big too early (Capex Waste). If a warehouse runs above 90–95% capacity, shipments get delayed and customers leave (Quality-of-Service Churn). The sweet spot is 75%–85%!

    If you drag `city` into a map visual, Power BI sends text strings to Bing Maps—sometimes plotting "Indore" or "Salem" in the wrong country! Using exact coordinates solves this 100%.

    2. Select latitude → Column tools → Data category → Latitude (also set Summarization = Don't summarize!).
    3. Select longitude → Column tools → Data category → Longitude (Summarization = Don't summarize!).

    Topic 4: Network SLA DAX 00:40 – 00:50

    Topic 4: Writing Network Uptime % & Fault Density Measures in DAX

    Each month has 43,200 minutes (`30 days × 24 hrs × 60 mins`). Let's convert `downtime_minutes` into an executive Network Uptime % SLA measure.

    // Total Possible Tower-Minutes in filtered period (43,200 mins per tower-month):
    Total Possible Minutes = COUNTROWS(fact_tower_metrics) * 43200

    Total Downtime Minutes = SUM(fact_tower_metrics[downtime_minutes])

    Network Uptime % = 1 - DIVIDE([Total Downtime Minutes], [Total Possible Minutes], 0)

    Avg Faults per Tower-Month = AVERAGE(fact_tower_metrics[fault_count])
