    Topic 1: The Matrix Visual — Power BI's Interactive Pivot Table

    Unlike a flat Table visual, a Matrix lets you nest multiple hierarchy levels on Rows and Columns with +/- expand icons and heatmap coloring.

    Configuring the Cohort Matrix on Page 2
    • Rows Field Well: Drag dim_plans[segment] ➔ dim_plans[plan_name] ➔ dim_towers[tower_tier].
    • Columns Field Well: Drag dim_subscribers[Vintage_Cohort] (2023Q1 to 2025Q4).
    • Values Field Well: Drag [Churn Rate %] and [Total Subscribers].
    • Turn on Stepped Layout = Off (`Format → Row headers → Options`) so Plan and Tier appear in clean separate columns!
    Mastering the 4 Drill-Down Icons (Top-Right of Visual)
    • Single Down Arrow (↓): Click-to-drill into one specific Plan (e.g., click PL015 to see its Metro, Tier-1, and Tier-2 split).
    • Double Down Arrow (⇊): Jumps to the next level across all plans at once.
    • Forked Pitchfork Arrow (⑂): Expands all hierarchies together (Plan + Tier) so you can sort the entire matrix from highest to lowest churn!
    Topic 2: Heatmap Engineering 00:14 – 00:22

    Topic 2: Building a DAX-Driven Heatmap Color Measure

    Why shouldn't you use Power BI's default color scale blindly? Because a cohort with 2 subscribers where 1 churned shows 50% churn—creating false alarms!

    // Guardrail Measure: Only flag cohorts with meaningful sample size (>= 50 subscribers)
    Cohort Heatmap Color =
    VAR SubsCount = [Total Subscribers]
    VAR ChurnVal = [Churn Rate %]
    RETURN
      SWITCH(
        TRUE(),
        SubsCount < 50, "#1E293B", -- Neutral dark slate for tiny sample sizes
        ChurnVal >= 0.50, "#E11D48", -- Crimson Alert (>= 50% Churn!)
        ChurnVal >= 0.18, "#D97706", -- Amber Warning (18% - 49%)
        "#0F766E" -- Healthy Teal (< 18%)
      )
    Format Visual → Cell elements → Background color → Format style: Field value → Select `[Cohort Heatmap Color]`

    Topic 7: Concentration Math 01:02 – 01:12

    Topic 7: DAX Concentration Ratio — Proving Disproportionate Impact (Q1c)

    Question 1c asks: "What share of total churned subscribers come from the worst cohort? Express this as a concentration ratio."

    What Is a Concentration Ratio?

    Concentration Ratio = (% Share of Total Churned Subscribers) ÷ (% Share of Total Subscriber Base). If churn were uniform across JioWave, a cohort holding 3% of subscribers would cause 3% of churn (Concentration Ratio = 1.0×). Anything above 3.0× proves severe structural concentration!

    Churn Concentration Ratio =
    VAR CohortChurned = [Churned Subscribers]
    VAR AllChurned = CALCULATE([Churned Subscribers], ALL(dim_subscribers), ALL(dim_plans), ALL(dim_towers))
    VAR ShareOfChurn = DIVIDE(CohortChurned, AllChurned, 0)

    VAR CohortSubs = [Total Subscribers]
    VAR AllSubs = CALCULATE([Total Subscribers], ALL(dim_subscribers), ALL(dim_plans), ALL(dim_towers))
    VAR ShareOfBase = DIVIDE(CohortSubs, AllSubs, 0)
    RETURN
      DIVIDE(ShareOfChurn, ShareOfBase, 0)
